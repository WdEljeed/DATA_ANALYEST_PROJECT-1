# DATA_ANALYST_PROJECT-1

A comprehensive SQL data analysis project on Retail Sales data. This repository demonstrates end-to-end data handling, including table creation, data cleaning, and exploratory data analysis (EDA). It features 10 business-driven SQL queries solving real-world problems using aggregations, window functions, CTEs, and CASE statements.

##  Project Overview
This project focuses on analyzing a Retail Sales dataset using **PostgreSQL**. The goal is to demonstrate core SQL skills by taking raw transactional data, cleaning it, exploring it, and answering 10 specific business questions. 

##  Tools Used
*   **Database Engine:** PostgreSQL
*   **IDE:** pgAdmin 4 / VS Code
*   **Dataset:** Retail Sales CSV

##  Database Schema
The project uses a single table named `retail_sales` with the following columns:
*   `transactions_id` (Primary Key)
*   `sale_date`
*   `sale_time`
*   `customer_id`
*   `gender`
*   `age`
*   `category`
*   `quantiy` (Note: typo in original dataset)
*   `price_per_unit`
*   `cogs`
*   `total_sale`

## 🧹 Step 1: Data Cleaning
Before analysis, the data was inspected for missing (NULL) values. Any rows containing NULL values in critical columns were deleted to ensure accurate calculations.

##  Step 2: Data Exploration
Basic exploration was performed to understand the dataset (total sales, unique customers, and unique categories).

##  Step 3: Business Problems Solved (Queries)
Here are the 10 business questions answered in the `sql_query_p1.sql` file:

1.  **Daily Sales:** Retrieved all sales made on a specific date (`2022-11-05`).
2.  **Filtered Transactions:** Found 'Clothing' sales in Nov-2022 where quantity was greater than 10.
3.  **Category Revenue:** Calculated the total sales revenue generated by each product category.
4.  **Customer Demographics:** Found the average age of customers who bought from the 'Beauty' category.
5.  **High-Value Transactions:** Filtered all transactions where the total sale was greater than $1000.
6.  **Gender Breakdown:** Calculated the total number of transactions made by each gender within each category.
7.  **Best Selling Month:** Found the best-selling month for each year (using `EXTRACT`, `GROUP BY`, and `RANK()` Window Function).
8.  **Top Customers:** Identified the Top 5 customers based on their total spending.
9.  **Category Popularity:** Found the number of unique customers who purchased from each category.
10. **Shift Analysis:** Created shifts (Morning, Afternoon, Evening) using a `CASE` statement and a `CTE` to count orders per shift.

##  How to Run This Project
1. Create a database in PostgreSQL.
2. Run the first query in `sql_query_p1.sql` to create the `retail_sales` table.
3. Import the `Retail_Sales.csv` data into the table.
4. Run the subsequent queries to see the data cleaning and analysis in action.
